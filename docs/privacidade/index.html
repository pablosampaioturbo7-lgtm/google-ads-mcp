Política de Privacidade

Esta política explica como o Turbo7 Agente de Tráfego, ferramenta interna da Turbo7 Marketing de Planejados, trata os dados acessados por meio da Google Ads API, em conformidade com a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

1. Dados acessados

Com a autorização do usuário via login Google (escopo https://www.googleapis.com/auth/adwords), a ferramenta acessa dados das contas de Google Ads às quais esse usuário já tem permissão: estrutura de campanhas, métricas de desempenho (impressões, cliques, custo, conversões) e configurações de anúncios. Também é usado o endereço de e-mail da conta Google para identificar o usuário no login.

2. Finalidade

Os dados são usados exclusivamente para gerar relatórios, análises e recomendações de otimização das campanhas dos clientes da Turbo7. Não são vendidos, cedidos ou usados para publicidade.

3. Armazenamento e segurança

Os tokens de acesso OAuth ficam armazenados de forma criptografada no Google Cloud (Firestore) do projeto da Turbo7, apenas pelo tempo necessário para manter a sessão do usuário. Os dados de campanha são consultados sob demanda e não são guardados em banco próprio da ferramenta.

4. Compartilhamento

Os resultados das consultas são processados pelo assistente de IA Claude, da Anthropic, utilizado pela equipe da Turbo7. Não há outro compartilhamento com terceiros.

5. Uso dos dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Direitos do titular e revogação

O usuário pode revogar o acesso a qualquer momento em myaccount.google.com/permissions. Pedidos de acesso, correção ou exclusão de dados podem ser feitos pelo e-mail abaixo.
